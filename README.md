# Midnight Ride

Downloads and updates for Midnight Ride, the Mac app for Molecule's customers.

- Download the latest version from the [releases](https://github.com/DovisDemo/midnightride-releases/releases/latest) or from [midnightride.app](https://midnightride.app).
- Installed copies check for new versions and ask before installing them. Each release carries the `appcast.xml` the app checks.
- Every update is signed with Midnight Ride's own key and notarized by Apple. The app refuses any update that isn't signed with that key.

This repo holds only the release files. The app's code is private.
